# Изменения

## 0.3.1 — 2026-10-31

- Исправлена изоляция тестов установки и релиза от XDG/AMNEZIA-переменных окружения CI.
- Внутренние отчёты аудита и планы удалены из зависимостей установки, Docker-контекста и релизного архива.
- Тесты подтверждают установку без внутренних документов и их исключение из архива.
- Версия CLI, архив и инструкция выпуска согласованы для v0.3.1.

## 0.3.0 — 2026-10-31

- Независимые режимы VPN-only, proxy-only и совместный запуск.
- Ожидание успешного VPN handshake с настраиваемым таймаутом и очисткой при ошибке.
- Команды apm/apm-gui, установка/обновление/удаление, config init и doctor.
- Runtime-снимок активной сессии, восстановление после аварии и диагностика.
- Запуск CLI/GUI через sandbox, активные proxy-порты и проверка transport guard.
- Пользовательский конфиг только через --config, AMNEZIA_PROXY_CONFIG или XDG-путь.
- Воспроизводимый Linux-архив, SHA256, manifest и проверка установки из архива.
- Исправлена совместимость f-string установщика с Python 3.11 (Debian Bookworm); добавлена проверка синтаксиса.
- Лицензия MIT. AWG, 3proxy и прочие внешние зависимости в архив не включены.
